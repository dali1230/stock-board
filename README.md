# 个人工作台

一个轻量的个人工作导航页，把每天要用的网站集中到一屏，点开即用。

## 功能

- **分组导航**：股票投资 / 电商运营 / 内容创作 / AI 工具 / 常用办公，五类快捷入口开箱即用
- **智能搜索框**：输入关键词用百度/必应/Google 搜索；直接输入网址则自动跳转
- **实时时钟**：日期、星期、时间与时段问候
- **深浅色主题**：一键切换，自动跟随系统偏好
- **编辑模式**：点右上角 ✏️ 可随时增删快捷方式，改动保存在浏览器本地
- **响应式布局**：手机、平板、电脑自适应

## 使用

直接用浏览器打开 `index.html` 即可，无需安装任何依赖、不需要服务器。

## 自定义

- **增删网站**：点右上角 ✏️ 进入编辑模式 → 卡片右上角 × 删除 / 卡片下方「＋ 添加」
- **改默认内容**：编辑 `index.html` 中的 `DEFAULT_DATA` 数组
- **数据存储**：你的自定义内容保存在浏览器 `localStorage`（key: `worknav.data.v1`），换浏览器或清理缓存会重置为默认

## 技术栈

原生 HTML + CSS + JavaScript，单文件，零依赖。
