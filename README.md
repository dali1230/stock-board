# A股自选股与持仓看板

一个零依赖、单文件的 A 股自选股与持仓跟踪看板。打开 `index.html` 即可使用，数据保存在浏览器本地，不上传任何服务器。

## 功能

- **自选列表**：名称 / 代码、现价、涨跌幅、持仓数量、成本价、市值、浮动盈亏、盈亏率
- **持仓汇总**：持仓总市值、累计浮动盈亏、今日盈亏、持仓成本，涨红跌绿（A 股习惯）
- **仓位分布**：Top 5 持仓占比环形图，自动合并"其他"
- **今日涨跌排行**：按涨跌幅横向条形图
- **行情刷新**：点击「刷新行情」尝试从东方财富公开行情接口拉取最新价格（JSONP，无需后端）；拉不到时可点任意行手动填写价格
- **数据本地存储**：`localStorage` 自动保存，刷新页面不丢
- **导入 / 导出**：一键导出 JSON 备份，换电脑时导入即可
- **深浅色主题**、移动端自适应

## 使用

1. 双击打开 `index.html`（推荐 Chrome / Edge）
2. 首次打开带 5 只示例股票，可直接改数据或全部删掉
3. 点「＋ 添加股票」录入：代码（6 位）、名称、现价、昨收、成本价、持仓数量
4. 点任意一行即可编辑；不填成本价和数量则为"仅自选、不持仓"

### 关于行情刷新

行情来自东方财富公开接口 `push2.eastmoney.com`，通过 JSONP 调用，不需要任何 Key。

- 该接口为公开数据，可用性由对方决定，不保证长期稳定
- 若所在网络受限或接口变更，刷新会提示失败，手动填价不受影响
- 价格仅作参考，不构成任何投资建议

## 部署到 GitHub Pages

仓库推到 GitHub 后，在 **Settings → Pages** 里把 Source 设为 `main` 分支的 `/ (root)`，等 1 分钟左右即可通过
`https://<用户名>.github.io/<仓库名>/` 访问。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建、无外部 CDN 依赖，可离线使用
- 图表用内联 SVG 手绘，避免引入第三方图表库
- 单文件结构，方便直接丢到任何静态托管
